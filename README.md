 CinéTrack

Catalogue de films et séries en JavaScript (ES Modules), alimenté par une API MockAPI.

 Fonctionnalités
Cards (image, titre, année, type)
Recherche et filtre par type (Tous, Films, Séries)
Pagination (8 par page)
Modal de détail
Favoris (cœur, sidebar, bouton X) sauvegardés dans localStorage
Message d’erreur si l’API échoue
🛠️ Technologies

HTML, Tailwind CSS, JavaScript (ES Modules), Fetch API

🚀 Lancement

Cloner le repo, puis ouvrir index.html avec Live Server (les modules ES nécessitent un serveur local).
